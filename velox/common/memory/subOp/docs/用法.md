# 脚本

## 编译脚本

```shell
cd /home/rl/0211/v1/velox
mkdir build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release  -DENABLE_ENHANCED_HASH_AGG_ADAPTER_DEBUG=0 # 显式关掉adapter debug，以免历史cache
# cmake .. -DCMAKE_BUILD_TYPE=Release -DENABLE_ENHANCED_HASH_AGG_ADAPTER_DEBUG=1 # 显式开启adapter debug，以免历史cache
make -j$(nproc)
# 于是在velox/common/memory/subOp里生成libxxx.so
```
